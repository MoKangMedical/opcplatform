1. 找准1-3个精准主题
2. 建立自媒体主页，持续输出内容
3. 日更3-5条短内容 + 每周1-2篇长内容
4. 第7天起推出微报价（$1000/4次1对1服务）
5. 每周30条私信，60天累计240条
